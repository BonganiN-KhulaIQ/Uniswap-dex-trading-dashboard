# Uniswap DEX Trading Activity Dashboard

## Project Overview

This project analyzes trading activity on Uniswap using Dune Analytics and SQL.

The dashboard explores:

- Daily Trading Volume (USD)
- Daily Number of Trades
- Average Trade Size (USD)
- Daily Unique Traders

The goal is to understand how trading activity changes over time on the Ethereum blockchain.
