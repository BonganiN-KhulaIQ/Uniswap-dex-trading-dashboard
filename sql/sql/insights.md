# Key Insights

## Daily Trading Volume
Daily trading volume highlights how much value flowed through Uniswap each day.

## Daily Number of Trades
This metric measures protocol activity by counting executed trades.

## Average Trade Size
Average trade size provides insight into whether trading was dominated by larger or smaller transactions.

## Daily Unique Traders
Unique trader counts indicate the number of distinct wallets interacting with Uniswap each day.
